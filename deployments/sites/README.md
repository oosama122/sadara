# موقع كلية الصدارة المستضاف

نسخة مستقلة من الواجهة الحالية مع واجهات بيانات تعمل في Cloudflare Workers، وقاعدة D1 للطلبات والرسائل والإعدادات والمحتوى، وR2 للصور المرفوعة.

- الموقع العام وملفاته في `public/`، ولوحة الإدارة في `public/dashbord/`.
- API في `app/server/service.mjs`، وبنية قاعدة البيانات في `db/schema.ts` وترحيلاتها في `drizzle/`.
- بيانات البداية في `app/server/seed.json` تتضمن المحتوى العام فقط؛ لا تُنسخ قواعد بيانات أو حسابات أو طلبات الموقع المحلي.
- دخول الإدارة يستخدم هوية ChatGPT التي تتحقق منها منصة Sites، ويقتصر على البريد المحدد في متغير الاستضافة `SADARA_ADMIN_EMAIL`. علامة المتصفح `sites-session` ليست صلاحية دخول؛ يفحص الخادم هوية المالك في كل عملية.
- يُدار الوصول العام أو الخاص من إعدادات Sites. تبدأ النسخة خاصة بالمالك، وتبقى صلاحيات الإدارة مقيدة به عند إتاحة الموقع للزوار.

يتطلب البناء Node.js 22.13 أو أحدث. الأوامر المعتادة:

```sh
npm run install:ci
npm run db:generate
node tests/service.test.mjs
npm run build
```

طبّق الترحيلات المحلية عبر Wrangler كما في تعليمات قالب Sites. تتولى منصة Sites تطبيق الترحيلات المستضافة قبل نشر Worker، وتوفر ارتباطي `DB` و`BUCKET` المحددين في `.openai/hosting.json`.

الأسرار ومتغيرات الإنتاج تحفظ في إعدادات الاستضافة؛ لا تضعها في المصدر أو ملفات الواجهة. ملف `.dev.vars` المحلي مستثنى من Git والنشر.
